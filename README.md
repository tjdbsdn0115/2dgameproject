# MBTIDUNGEON

성격이 능력이 되는 2D 퍼즐 던전 탈출 게임입니다. 네 쌍의 MBTI 지표에서 하나씩 선택해 4개 능력을 조합하고, 같은 던전을 서로 다른 전략으로 공략합니다.

- 저장소 이름: `2dgameproject`
- 개발 기술: Python, pico2d
- 플레이 방식: 1인용 탑다운 퍼즐 어드벤처
- 현재 단계: 1차 발표 기획 및 요구사항 정리. 게임 실행 코드는 아직 포함하지 않습니다.

## 핵심 규칙

1. E/I, S/N, T/F, J/P에서 각각 하나를 선택해 16개 유형 중 하나를 만듭니다.
2. 선택한 지표에 대응하는 4개 능력을 사용합니다.
3. 함정, 문, 퍼즐, NPC가 있는 던전에서 열쇠를 찾고 출구에 도달합니다.
4. 모든 조합에 기본 해결 경로가 있으며, 능력은 공략 속도와 안전성을 바꿉니다.
5. 체력이 0이면 실패합니다. 다른 조합으로 재도전하고 시간과 피해 기록을 비교합니다.

MBTI는 실제 개인의 능력을 판단하는 기준이 아닌 게임 속 창작 설정입니다.

## 저장소 작업

이 폴더는 상위 `2026-2DGP`와 별도의 Git 저장소입니다. VS Code에서 이 폴더를 직접 열거나, 소스 제어에서 `2dgameproject` 저장소를 선택해 작업합니다.

```sh
git status
git add .
git commit -m "docs: update game planning documents"
git push origin main
```

게임 구현 전이므로 설치 및 실행 명령은 구현을 시작할 때 추가합니다.
