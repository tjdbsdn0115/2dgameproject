# MBTIDUNGEON

성격이 능력이 되는 2D 퍼즐 던전 탈출 게임입니다. 네 쌍의 MBTI 지표에서 하나씩 선택해 4개 능력을 조합하고, 같은 던전을 서로 다른 전략으로 공략합니다.

- 저장소 이름: `2dgameproject`
- 개발 기술: Python, pico2d
- 플레이 방식: 1인용 탑다운 퍼즐 어드벤처
- 현재 단계: 2주차 발표용 프로토타입. MBTI 선택, 맵 이동과 벽 충돌, 능력 데이터 및 연습 효과를 구현했습니다.

## 실행

Windows와 Python 3 환경에서 아래 명령으로 실행합니다. 최대화된 창으로 시작하며 게임의 기준 해상도는 1280×800입니다. 프로젝트에 포함된 Cinzel과 나눔명조 글꼴을 사용합니다.

```powershell
python -m pip install -r requirements.txt
python main.py
```

`run_game.bat`을 더블클릭해 실행할 수도 있습니다.

실행하면 로고가 페이드 효과와 함께 표시되고 약 2.8초 후 타이틀 메뉴로 전환됩니다. Enter·Space 또는 클릭으로 로고를 건너뛸 수 있습니다. 타이틀에서 방향키·W/S 또는 마우스로 던전 입장, 조작 방법, 게임 종료를 선택합니다. 던전 입장은 MBTI 선택 화면으로 연결됩니다.

| 조작 | 동작 |
| --- | --- |
| 마우스 | E/I, S/N, T/F, J/P 선택 |
| Enter | 네 지표 선택 후 입장 |
| WASD 또는 방향키 | 이동 |
| Space | NPC·석판 대화, 열쇠 획득, 출구 열기 |
| 1~4 | 선택한 네 능력 사용 |
| R | 선택 화면으로 복귀, 새 입장 시 진행 상태 초기화 |
| F11 또는 Alt+Enter | 모든 화면에서 전체화면·창 모드 전환 |
| Esc | MBTI 선택 화면에서 타이틀로 돌아가기, 던전·타이틀에서 종료 |

전체화면은 현재 모니터 크기에 맞춰 표시합니다. 전체화면을 해제하면 작업표시줄을 제외한 화면을 채우는 최대화된 창으로 돌아갑니다. 창의 크기도 마우스로 조절할 수 있습니다. 게임 화면은 1280×800 비율을 유지하고 남는 공간에는 검은 여백을 둡니다. 마우스 입력도 같은 비율로 보정합니다.

## 이번 제작본

- 20×12 고정 타일 맵과 4방향 이동을 구현했습니다. 대각선 속도를 보정하고, 축별 충돌과 작은 이동 단계로 벽 관통을 방지합니다.
- 대기·걷기·충돌 PNG 프레임을 연결했습니다. 왼쪽 이동은 오른쪽 프레임을 반전해 표시합니다.
- 16개 MBTI 유형을 구성하고 각 유형에 4개 능력을 자동 장착합니다.
- 8개 능력의 연습 효과와 쿨타임을 구현했습니다. E/F는 안내자, T는 석판 가까이에서 사용합니다.
- I는 가까운 함정 경고, S는 함정과 열쇠 표시, N은 목표 방향, J는 연습 함정 정지, P는 속도 증가를 시연합니다.
- F는 안내자 NPC의 체력을 25 회복하도록 설정했습니다. 능력 수치와 범위는 시연용 초기값입니다.
- 열쇠 획득과 출구 조건으로 연습 맵 탐색을 마칠 수 있습니다.

정식 함정의 플레이어 피해·체력·실패 처리, 문 퍼즐, 결과 기록 비교, 16개 유형의 완성 던전 플레이 검증은 3~5주차 후속 개발 항목입니다. 안내자는 은발과 보라색 학자 로브를 입고 책과 랜턴을 든 전용 NPC PNG를 사용합니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `main.py` | pico2d 이벤트 처리, MBTI 선택, 맵과 HUD, 애니메이션 |
| `logo_mode.py` | 시작 로고, 페이드와 타이틀 자동 전환 |
| `title_mode.py` | 던전 타이틀 메뉴, 조작 안내, 키보드·마우스 선택 |
| `game_model.py` | 유형·능력 연결, 이동과 충돌, 쿨타임, 연습 상호작용 |
| `data/abilities.json` | 8개 능력의 이름, 효과, 지속 시간, 쿨타임과 범위 |
| `data/dungeon.json` | 벽·바닥 배치와 주요 객체 위치 |
| `assets/dungeon_atlas.png` | ImageGen으로 제작한 게임 아틀라스 |
| `assets/title_background.png` | 타이틀과 MBTI 선택 화면의 던전 배경 |
| `assets/sprites/` | 개별 타일·캐릭터·열쇠·출구 PNG와 안내자 NPC PNG |
| `verify_week2.py` | 16개 유형, 충돌 및 연습 능력 규칙 검증 |

```powershell
python verify_week2.py
```

검증 결과는 `output/verification.json`에 저장합니다. 게임 화면 캡처를 다시 만들 때는 Pillow를 설치하고 `python main.py --capture`를 실행합니다. 캡처는 같은 게임 렌더러를 사용합니다.

## 핵심 규칙

1. E/I, S/N, T/F, J/P에서 각각 하나를 선택해 16개 유형 중 하나를 만듭니다.
2. 선택한 지표에 대응하는 4개 능력을 사용합니다.
3. 함정, 문, 퍼즐, NPC가 있는 던전에서 열쇠를 찾고 출구에 도달합니다.
4. 모든 조합에 기본 해결 경로가 있으며, 능력은 공략 속도와 안전성을 바꿉니다.
5. 체력이 0이면 실패합니다. 다른 조합으로 재도전하고 시간과 피해 기록을 비교합니다.

MBTI는 실제 개인의 능력을 판단하는 기준이 아닌 게임 속 창작 설정입니다.
