# 게임 글꼴

영문 게임명과 MBTI 표시는 Cinzel을 사용합니다. 한글 메뉴와 제목은 나눔명조 Bold, 설명과 HUD는 나눔명조 Regular를 사용합니다. 파일을 프로젝트에 포함하며 pico2d가 직접 불러옵니다.

능력 선택 화면의 지표와 조합 결과는 Cinzel Decorative Bold를 사용합니다. 능력 이름과 화면 제목은 나눔명조 ExtraBold에 음영을 더해 각인처럼 표시합니다.

공식 Google Fonts 저장소에서 받은 원본 파일과 각 글꼴의 OFL 라이선스를 함께 보관합니다.

- Cinzel 원본과 라이선스는 https://github.com/google/fonts/tree/main/ofl/cinzel 에서 확인할 수 있습니다.
- 나눔명조 원본과 라이선스는 https://github.com/google/fonts/tree/main/ofl/nanummyeongjo 에서 확인할 수 있습니다.
- Cinzel Decorative 원본과 라이선스는 https://github.com/google/fonts/tree/main/ofl/cinzeldecorative 에서 확인할 수 있습니다.
